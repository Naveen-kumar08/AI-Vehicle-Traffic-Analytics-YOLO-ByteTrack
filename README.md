# 🚗 AI Vehicle Traffic Analytics

An AI-based vehicle traffic analytics system that uses **YOLO11, ByteTrack, and OpenCV** to detect, track, classify, count, and analyze vehicles from traffic videos.

The system supports vehicle detection, unique ID tracking, line-crossing counting, trajectory visualization, approximate speed estimation, vehicle image capture, CSV/Excel reporting, and a live traffic analytics dashboard.

---

## 📌 Project Overview

The **AI Vehicle Traffic Analytics** project is a computer vision-based traffic monitoring system designed to automatically analyze vehicles from a traffic video.

The system uses **YOLO11** for vehicle detection and **ByteTrack** for multi-object tracking. Each detected vehicle is assigned a tracking ID, and its movement is monitored throughout the video.

A virtual counting line is used to count vehicles crossing a specific point. The system also classifies vehicles into different categories and generates traffic analytics.

### Supported Vehicle Classes

- 🚗 Car
- 🏍️ Motorcycle
- 🚌 Bus
- 🚚 Truck

Key Features
1. 🚗 Vehicle Detection

YOLO11 is used to detect vehicles in each frame of the traffic video.

The system detects the following vehicle categories:

Car
Motorcycle
Bus
Truck

Each detection provides:

Bounding box
Vehicle class
Confidence score

Example:
ID 02 | Car | 0.61
ID 17 | Car | 0.58
ID 68 | Car | 0.76
2. 🎯 Vehicle Tracking

ByteTrack is used to track vehicles across multiple frames.

Each tracked vehicle receives a unique tracking ID.

Example:

Vehicle ID: 02
Vehicle Type: Car
Confidence: 0.61

The tracking ID allows the system to follow the same detected vehicle across video frames.

The tracking ID is generated by ByteTrack and does not represent the real-world identity or license number of a vehicle.

3. 📊 Vehicle Counting

A virtual counting line is automatically placed in the traffic video.

When a tracked vehicle crosses the line, it is recorded as a counted vehicle.

             VEHICLE
                ↓
                ↓
────────────────────────────────
          COUNTING LINE
────────────────────────────────
                ↓

The system provides counts for:

Total Vehicles
Cars
Motorcycles
Buses
Trucks
4. 🛣️ Vehicle Trajectory

The movement history of each tracked vehicle is displayed as a trajectory line.

This allows the movement path of vehicles to be visualized directly on the processed video.

5. 🚦 Approximate Speed Estimation

The system estimates vehicle speed based on the movement of tracked vehicles between video frames.

The project uses a configurable pixel-to-meter conversion value.

METERS_PER_PIXEL = 0.05

Note: The speed value is an approximate estimation. Accurate real-world speed measurement requires proper camera calibration, scene measurements, or homography-based calibration.

6. ⚠️ Speeding Detection

A configurable speed limit is used to identify vehicles whose estimated speed exceeds the configured threshold.

Example:

SPEED_LIMIT_KMPH = 60

Vehicles exceeding the configured limit are marked as speeding.

7. 📷 Vehicle Image Capture

The system saves an image of each unique tracked vehicle.

Example:

⚠️ Limitations
Speed estimation is approximate unless the camera is properly calibrated.
ByteTrack IDs represent tracking identities within the processed video and do not identify the actual vehicle.
Detection performance depends on video quality, lighting, camera angle, occlusion, and vehicle visibility.
CPU processing may be slower than real-time.
Vehicle counting depends on correct counting-line placement and tracking performance.
The speed conversion value should be calibrated for a specific camera setup for meaningful real-world speed measurement.
